Making lag disappear

In an online shooter your input travels to the server and back before you see it move. Client-side prediction moves you at once and lets the server correct you later. This is the kind of code I write at Vertigo.

Click or tap either arena to move, or use the arrow keys. The outlined ring is the position the server has confirmed. A simplified simulation, not game footage.
